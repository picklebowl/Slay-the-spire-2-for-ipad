# iPad 安装与续签助手

连接一根 USB 线，在 Windows 助手中安装和续签《杀戮尖塔2》。无需 Mac、命令行、手动处理资源包或启动 JIT。

## 开始使用

1. 下载 `StS2-iPad-Assistant-Setup.exe`，运行安装并打开助手。程序自带需要的运行环境；缺少 WebView2 时安装器自动下载。
2. 用 USB 连接 iPad，解锁后确认“信任此电脑”。首次安装需在电脑的 Steam 中购买并安装匹配版本的《杀戮尖塔2》。
3. 在助手中亲自登录 Apple 账号、完成双重验证。可选择将登录保存在 Windows 凭据管理器，方便后续一键续签。
4. 保存退出 iPad 游戏，勾选已关闭游戏，点击 **一键安装 / 配置**。助手自动检查并下载 Apple 组件、识别 Steam 游戏、准备资源、备份旧档、签名安装、传入资源并读回校验。
5. 按助手提示在 iPad 信任开发者，开启“设置 → 隐私与安全性 → 开发者模式”，重启并确认。完成后可拔线离线游玩。

账号密码、双重验证码、Windows 管理员授权、iPad 信任和开发者模式，均由你亲自确认。助手不会自动接受这些系统授权。

## 一键续签

免费签名约 7 天有效。到期前，将 iPad 接回联网电脑，打开助手，保存退出游戏，点击 **一键续签**。助手使用同一账号和同一安装包重新签名覆盖安装，检查原应用和存档仍在；不卸载、不重传约 2 GB 资源、不导入或重置进度。

如果之前选择了保存登录，助手会自动恢复该账号。Apple 可能要求再次验证；没有保存登录时先亲自登录。续签不需要电脑仍安装 Steam 游戏。

存档备份保存在助手自己的数据目录，成功后界面显示位置。不要卸载游戏来续签；卸载会删除 iPad 的本地数据。

## 支持范围

- Windows 10/11 x64、USB 连接的 iPad。首次安装建议电脑有 7 GB 以上可用空间；iPad 需容纳约 2 GB 资源与游戏。
- 当前安装包只适配游戏 **v0.111.0**。助手同时检查版本和程序集哈希；Steam 更新后不能混用，需等待配套构建。
- 游戏可离线运行；下载工具和免费续签需要联网。永久免签不适用于本项目当前设备方案。
- 安装器和便携版含已购买游戏的私有构建，下载仅限获授权的私有仓库用户。原版素材只从你本机 Steam 安装处理，不上传、不公开。
- 此助手基于 [iloader](https://github.com/nab138/iloader) 的 MIT 开源签名流程，使用独立的应用设置与凭据命名空间，属于项目定制版本，不是 iloader 官方产品。

## 遇到问题

- 找不到 iPad：解锁、重新接线，点设备区域“刷新”；缺 Apple 组件时先点击安装让助手补齐，并亲自确认 Windows 管理员授权。提示重启时先重启电脑。
- 找不到游戏：展开“未自动找到 Steam 游戏？”，选择 `Slay the Spire 2` 文件夹。不是原版 Steam 游戏或版本不匹配时，助手会停止。
- 传输中断：资源先写临时文件，读回校验成功才启用。重新连接后重试，原游戏资源和存档不会被覆盖。
- 续签账号不同：切回原安装账号。助手不自动删除账号、证书或应用来腾限额；Apple 提示证书限额时由你在明确的账号弹窗处理。
- 首次进入菜单卡顿：全量着色器预热需等待完成；彻底关闭再启动。本项目已在 iPad Air 2025 通过至少 30 分钟顺滑离线玩法验收。

安装助手 v0.1.1 已在当前 Windows 电脑及 iPad Air 2025 完成安装、USB 一键续签和存档保留验证；重开助手能恢复已保存账号。完全没有 Apple 组件的干净 Windows 环境首次安装尚未实测。详细验收范围请以仓库 README 为准。
