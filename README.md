# 杀戮尖塔2 · iPad 安装与续签助手

**一台 Windows 电脑，一根 USB 线。自动准备环境、安装游戏，后续一键续签。**

游戏原生运行在 iPad，可离线游玩；无需 Mac、越狱、JIT 或电脑串流。首次安装从你已购买的 Steam 游戏处理资源，不需要手动运行脚本、编译或传文件。

> 当前状态：原生游戏移植已在 iPad Air 2025 完成真机验收，连续离线游玩至少 30 分钟顺滑。新的安装助手已通过前端编译与 20 项本地数据安全测试；Windows 安装器构建、干净环境安装和真机一键续签仍在验证中。请勿将原游戏验收视为新助手已全部通过。

## 下载与开始使用

[**下载页面 →**](https://github.com/picklebowl/Slay-the-spire-2-for-ipad/releases/tag/assistant-v0.1.1)（Windows 构建成功后提供安装器） · [构建进度](https://github.com/picklebowl/Slay-the-spire-2-for-ipad/actions/workflows/build-assistant.yml) · [详细新手指南](windows-assistant/START-HERE.md)

| 首次安装需要 | 后续续签需要 |
|---|---|
| Windows 10/11 x64、联网 | 联网 Windows 电脑 |
| 一根可传数据的 USB 线、iPad | 同一 iPad 和 USB 线 |
| 在电脑购买并安装匹配版本的 Steam《杀戮尖塔2》 | 不需要电脑仍安装 Steam 游戏 |
| Apple 账号、亲自完成双重验证 | 原安装账号；已保存登录可自动恢复 |
| 电脑建议至少 7 GB 空闲空间，iPad 约 2 GB 资源空间 | 保留已安装游戏和资源 |

1. 下载并运行 `StS2-iPad-Assistant-Setup.exe`，打开助手。
2. 用 USB 连接 iPad，解锁后确认 **信任此电脑**。只有一台 USB 设备时自动选择。
3. 在助手账号区域亲自登录 Apple 账号并完成验证，可自行选择保存登录。
4. 保存退出 iPad 游戏，勾选已关闭游戏，点击 **一键安装 / 配置**。
5. 按提示在 iPad 信任开发者、开启开发者模式并重启确认。完成后拔线离线玩。

助手自带运行环境；缺少 WebView2 时安装器自动下载，缺少 Apple USB 组件时自动从 Apple 下载并校验后安装。Windows 管理员授权、Apple 登录与验证码、iPad 信任和开发者模式需要你亲自确认；助手不会绕过这些确认。

## 一键续签：保留资源和存档

免费签名约 **7 天**有效，到期前接回 USB，打开助手并点击 **一键续签**。

```mermaid
flowchart LR
    A[连接 USB，保存退出游戏] --> B[恢复已保存账号或亲自登录]
    B --> C[自动备份存档]
    C --> D[重新签名，覆盖安装]
    D --> E[检查同一应用和原存档]
    E --> F[成功，拔线离线游玩]
```

- 续签直接执行签名与覆盖安装，使用同一 IPA 和 Apple 账号。
- 不卸载游戏、不重传约 2 GB 资源、不导入或重置进度。
- 续签前自动备份本项目游戏存档，之后读回比较原文件。界面显示备份位置。
- 保存登录使用助手独立的 Windows 凭据管理器命名空间；未保存时先亲自登录。Apple 仍可能要求再次验证。
- 账号改变、文件版本不匹配、校验失败或 USB 中断时停止并说明原因，不自动删除应用或证书来腾限额。

## 自动完成的工作

| 功能 | 行为 |
|---|---|
| 环境检查 | 检查 Apple 设备通信服务；缺少时下载已验证的官方安装包 |
| 游戏识别 | 检测 Steam 默认与其他游戏库；找不到时可点击选目录 |
| 版本保护 | 同时验证游戏版本与程序集 SHA256，避免旧 IPA 配新资源 |
| 资源准备 | 从本机合法游戏处理资源，关闭 Sentry 入口，校验全部资源目录哈希 |
| USB 安装 | 使用 iloader 开源签名流程，直接完成签名和覆盖安装 |
| 资源传输 | 先写助手临时文件，完整读回 SHA256 一致才启用；中断可校验后续传 |
| 存档保护 | 安装/续签前备份，续签后核对；已有不同资源不自动覆盖 |
| 后续维护 | 一键续签；无需 Python、命令行或手动 Import IPA |

## 支持范围

当前配套游戏为 **v0.111.0**，验证设备为 **iPad Air 2025 / M3**。主菜单、战斗、拖牌、奖励、商店/事件、保存续局、后台恢复、声音、自然结算与历史记录已获用户真机确认。流畅度依据用户持续操作观察，未进行数值 FPS、温度或内存基准测量。

关闭 Steam/Sentry/mod 初始化及主菜单联机入口，保留单人本地存档。免费签名安装需要周期性联网续签；签名有效期间游戏可全程离线。当前方案不是永久免签。

Steam 更新后需要配套重建 IPA 和资源，本助手不会把不匹配版本装进去。此私有仓库及安装包含个人合法游戏副本的构建，只供获授权用户访问；不能直接把仓库改成公开。原版素材不上传，其他用户需有自己的合法 Steam 副本。

## 常见问题

**找不到 iPad？** 解锁、检查 USB 数据线并刷新。Apple 组件安装后提示重启时先重启电脑；iPad 的 iTunes Store 与电脑 USB 驱动无关。

**找不到 Steam 游戏？** 展开助手的“未自动找到 Steam 游戏？”，选择 `Slay the Spire 2` 文件夹。版本不同会安全停止。

**首次启动卡顿？** 全量着色器预热需等待；完成后从后台彻底关闭再启动。原移植的实测卡顿在这一步后改善。

**续签失败或 Apple 报限额？** 保留错误，别卸载游戏。助手不自动注销账号、撤销证书或删除应用。使用原账号处理，并保留显示的存档备份。

**能自动同步电脑存档吗？** 本项目游戏各设备保存独立；续签只保护现有存档，不执行存档导入或自动同步。
